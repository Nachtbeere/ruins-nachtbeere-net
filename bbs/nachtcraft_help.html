도움말

 

기본 설명

 

이곳에서는 밤딸기에서 운용중인 모드와 플러그인, 그 외 게임 도움말의 기본적인 부분만 다룹니다. 더 자세한 설명이 필요하다면 공식 위키(wiki.minecraft.nachtbeere.net)를 참조 바랍니다.

 

인프라

이동과 생활의 편리함을 위해 밤딸기 서버에는 다음과 같은 인프라 시설들이 있습니다.

 

상점

구하기 번거롭거나 시간을 필요로 하는 아이템 중, 바닐라 아이템에 한하여 공식적으로 판매를 합니다.

 

고속도보

맵을 가로지르는 검은 도로입니다. 녹색으로 표시된 Thaumcraft의 여행석이 일정 간격으로 설치되어 빠른 이동을 돕습니다. 여행자의 신발과 퀀텀 수트를 착용한다면 약 시속 80km/h 의 속도로 달릴 수 있습니다.

 

고속도보 노선

  • 북산고속도보
    • 북촌 나들목
    • 남방 나들목
  • 여월고속도보(공사중)
  • 천해고속도보(공사중)

철도

철도는 궤간에 따라 바닐라 철도와 RealTrain 철도 두 가지가 있습니다. 바닐라 철도는 RailCraft 모드가 적용되었으나, 규격이 협궤이므로 가장 쉽게 설치하고 이용할 수 있습니다. RealTrain 철도는 실제 철도와 유사하게 동작하며, 궤간은 바닐라 협궤의 3배이기 때문에 100km/h 이상의 고속으로 달리는 것이 가능합니다.

 

철도 노선

노선의 성격에 따라 분류합니다. 바닐라 철도(RailCraft) 사용 노선이라면 아무것도 붙지 않고, RealTrain 사용 노선이라면 앞에 (R)이 붙습니다.

  • 간선, 광역철도
    • (R)대륙순환선
      • 길잡이의 섬
      • 잎사귀 숲
      • 신도시 (가)
      • CC04
      • CC05
      • CC06
      • CC07
      • 유키하바라
  • 도시철도
    • 유키하바라 도시철도 1호선

플러그인

문게이트

이 플러그인은 실시간으로 동작하며, 원거리 이동을 제공합니다. 모티브는 울티마와 마비노기의 문게이트이며, 작동 방식도 유사합니다. 현실 시간으로 30분에 한 번씩 10분간 움직이고, 열리는 포탈은 랜덤 지정된 위치로 단방향 이동만 가능합니다.

  • 문게이트 노선
    • 길잡이의 섬
    • 신도시 (가)
    • 유키하바라
    • 북촌

ChestShop

이 플러그인은 상거래 기능을 제공합니다. 인게임 텍스트 전체 한글화가 되어있습니다.

  1. 상자를 놓습니다. 판매를 위해서는 상자에 해당 아이템의 재고가 반드시 있어야 합니다.
  2. 상자 한 블록 위에 팻말을 놓고, 다음과 같이 작성합니다. 아이템 이름 대신 코드도 가능합니다.
    • 작성 예
      • (공백. 주인 이름으로 자동완성 됨)
      • 한번에 판매 될 갯수
      • 가격
      • 아이템 이름(코드)
  3. 가격 부분은 구매 가격(Bought)과 판매 가격(Sell)로 구분되며, 이 둘 사이는 콜론(:)으로 구분합니다. 만약 해당 인자 없이 작성한 경우(예: 39 또는 39:39), 앞에 있는 숫자가 구매 가격으로 결정됩니다. 만약 구매는 불가능하고 판매만 가능한 상점을 만들고 싶다면, "S [가격]" 또는 "[가격]" 과 같이 작성해야 합니다.
    • 작성 예
      • nachrcraft
      • 64
      • B 10:5 S
      • Diamond

LWC

이 플러그인은 블록 잠금 기능을 제공합니다. 인게임 텍스트 전체 한글화가 되어있습니다. 상자, 화로 등을 설치시 잠금이 없는 것이 기본값입니다. 아래 명령어 중 항목 아래의 명령어는 모두 같은 기능으로, 그 중 하나만 입력하시면 됩니다.

  • 잠금
    • /cprivate
    • /lwc create private
    • /lwc -c private
  • 패스워드 잠금
    • /cpassword <password>
    • /lwc create password <password>
    • /lwc -c password <password>
    • 사용 권한 취득
      • /cunlock <password>
  • 잠금 해제
    • /cpublic
    • /lwc create public
    • /lwc -c public
  • 잠금 제거
    • /cremove

Factions

이 플러그인은 진영 기능을 제공합니다. 밤딸기에서 일반 유저가 사용 가능한 기본 명령어만 수록합니다. 여기 수록되지 않은 고급 명령어는 위키 항목을 참조 바랍니다.

  • 기본 명령어
    • /f
      • list
        • 진영 목록을 봅니다.
      • f, faction
        • 자신의 진영 정보를 봅니다.
      • p, player
        • 타인의 진영 정보를 봅니다.
      • join <진영>
        • 진영에 가입합니다.
      • leave
        • 진영에서 탈퇴합니다.
      • status
        • 진영원들의 세력과 접속 상태를 봅니다.
      • home
        • 진영의 홈으로 이동합니다.
    • /f money
      • b, balance
        • 진영 은행의 자금 현황을 봅니다.
      • d, deposit <액수>
        • 진영 은행에 입금합니다.
      • w, withdraw <액수>
        • 진영 은행에서 출금합니다.
