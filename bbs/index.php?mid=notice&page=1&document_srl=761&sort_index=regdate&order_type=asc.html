일반 [완료] 게임 서버 작업 안내

관리자 2016.01.23 10:37 조회 수 : 223

원래 백업 서버 준비할 환경이 되면 하려 했는데, 어차피 이 시간에 사람도 없으니 서버를 내리고 작업하기로 했습니다.

  • 중단되는 서비스: 마인크래프트 멀티플레이 서버, OpenTTD 멀티플레이 서버, 마인크래프트 지도, 랭킹
  • 중단 사유: 시스템 하드웨어 업그레이드 및 OS 재설치
  • 예상 시간: 2016년 1월 23일 오전 2시 ~ 오전 6시피곤해서 조금 걸립니다

이용에 불편을 드려 죄송합니다.

 

----

 

완료 내역입니다.

 

운영 체제를 64비트 리눅스로 사용하는 것은 변함 없습니다. 시스템을 SSD에 새로 설치하는 과정에서 니트로베리를 위한 시스템 개선이 이루어졌기 때문에, 기존 모드 서버에도 미약한 성능 향상이 있을 수 있습니다. 또, 주문한 부품 하나가 늦게 와서, 다음 주 화~수 정도에 약 30~1시간 가량 추가 작업이 예정되어 있습니다. 양해 부탁 드립니다.

 

오랜 시간동안 접속이 불가능했던 점에 사과 드립니다.

 

감사합니다.
