접속 주소

connect.nachtbeere.net

 

서버 버전

1.7.10 (Forge 1614)

모드팩을 설치하지 않으면 접속이 불가능합니다.

모드팩의 버전이 맞지 않아도 접속이 불가능합니다.

 

클라이언트 모드팩 버전

(Forge 1448)

1.7.10-V2-160201

인스톨러 다운로드     /     바이너리 다운로드

                                     [미러 1]

 

설치와 접속 방법

  • Windows 또는 Mac에서 마인크래프트를 2015년 10월 이후에 설치했다면, 별도로 자바를 설치할 필요가 없습니다.
  • 모드팩을 업데이트 할 경우, 그냥 덮어씌우게 되면 오류가 발생할 수 있습니다. 이런 경우 겹치는 폴더들을 전부 제거하고 설치해주세요.

 

인스톨러

준비 중입니다.

 

바이너리

아래 내용은 바이너리에 포함된 DO-NOT-READ-ME.txt 에 쓰인 것과 동일한 내용입니다.

  1. 압축 파일 내의 "nachtcraft-mods" 폴더의 내용물을(nachtcraft-mods 폴더 자체를 복사하는 것이 아님) 자신의 운영체제에 맞게 복사해서 덮어씌워 주시기 바랍니다.
    1.  Windows Vista 이상이라면, C:\Users\<유저명>\AppData\Roaming\.minecraft 에 덮어씌워 주시기 바랍니다. 해당 폴더는 탐색기 주소창에 %appdata%\.minecraft 라고 타이핑함으로써 간편하게 접근할 수 있습니다.
    2. Mac의 경우, /Users/<사용자 이름>/Library/Application Support/minecraft 에 덮어씌워 주시기 바랍니다.
    3. Linux/UNIX 호환 운영체제의 경우 "$HOME/.minecraft" 에 덮어씌워 주시기 바랍니다.
  2. (모드팩을 처음 설치하시는 경우) "_기본 설정" 폴더 안의 파일을 복사한 뒤, modpacks 폴더 안의 nachtcraft 폴더에 넣어 주시기 바랍니다.
  3. (모드팩을 처음 설치하시는 경우) 마인크래프트 런쳐를 기동하신 후 좌하단의 New Profile을 클릭하세요.
  4. 새 창이 뜨면 다음과 같이 변경합니다. (추천)이라는 사족이 없는 단계는 모두 필수입니다.
    1. Profile Name: 원하시는 이름을 아무거나 입력하세요. (nachtcraft 등)
    2. Game Directory를 체크 후 다음과 같이 입력하세요.
      1. Windows의 경우: C:\Users\<유저명>\AppData\Roaming\.minecraft\modpacks\nachtcraft
      2. Mac의 경우: /Users/<사용자 이름>/Library/Application Support/minecraft/modpacks/nachtcraft
      3. Linux의 경우: "$HOME/.minecraft/modpacks/nachtcraft"
    3. (추천) Resolution(해상도)에 체크하시고 원하시는 대로 변경하세요. 1138 x 640을 추천합니다.
    4. Automatically ask Mojang for assistance with fixing crashes를 해제하세요. 별 도움 안 됩니다.
    5. Use version: 에서 1.7.10-LiteLoader1.7.10-Forge10.13.4.1448-1.7.10을 선택합니다.
      • 버전을 필히 제대로 확인하세요! 1.7.10-Forge10.13.4.1448-1.7.10가 아니라 1.7.10-LiteLoader1.7.10-Forge10.13.4.1448-1.7.10입니다!
    6. 전부 입력하셨으면 Save Profile을 눌러주세요.
    7. 좌하단의 Profile:에서 새로 만든 밤딸기 서버 프로파일을 선택하고 Play를 누릅니다. 이제 밤딸기 서버를 즐길 준비가 다 되었습니다! 
    8. (중요)특정 모드가 재배포 방지를 위해 인증키를 요구하기 때문에, 다음과 같은 절차를 따라야 합니다.
      1. 싱글 플레이에 새 세계를 만듭시다.
      2. 생성하기 전에 설정에서 '치트 허용'을 켭니다.
      3. /ngt dqj12ih68234vs 커맨드를 채팅에 입력합니다.
      4. 이제 화면 상단에 인증하라는 문구가 나오지 않습니다. 서버에 접속해 주세요.

 

참고 사항

  • 모드팩의 용량이 크기 때문에, 처음 마인크래프트를 기동할 때 시간이 조금 소요될 수 있습니다. 오류가 뜨지 않는 이상 문제가 생긴 것은 아니니 느긋하게 기다려주세요.
  • 런처의 Profile 선택을 이용해서 다양한 서버와 다양한 버전을 이용하실 수 있습니다. 밤딸기 서버를 이용하실 경우에만 설치 시 만드신 Profile을 선택해 플레이해주세요.
  • 처음 설치하셨을 경우 키 설정 등 게임 내 설정을 다시 하실 필요가 있습니다.
  • 즐거운 마인크래프트 되시길 바랍니다.

 

당황하지 마세요

  • 게임 내 싱글플레이 세이브나 서버 리스트가 없어져도 놀라지 마세요. 사라진 것이 아니라 Profile을 원래 쓰시던 것으로 변경하면 다시 사용하실 수 있습니다.
  • 게임 내 채팅에서 상대 머리 위에 말풍선이 나타나지 않는다면 Profile에서 버전을 잘못 고르신 경우입니다. 설치 과정을 참고해 버전을 올바르게 바꿔주세요.
  • 서버 접속 시 Mod Rejection이 나타난다면, 모드팩이 업데이트 된 것입니다. 모드팩을 새로 받아주세요.
  • 만약 32비트 자바를 사용중이시라면 자바가 사용 가능한 램 크기의 문제일 수도 있습니다. JVM Arguments에 -Xmx1024m을 입력해 저장하신 후 실행해보세요. 만약 PC에 설치된 램이 4GB 이상이라면 64비트 운영체제와 64비트 자바를 사용하시는 것을 권장합니다.
  • 제대로 시작되지 않는 경우 자바 버전 문제일 수도 있습니다: Edit Profile로 밤딸기 서버의 Profile을 연 뒤, Java Settings (Advanced) 안의 Executable을 체크하고 자신의 OS에 설치된 버전 7 이상의 자바 경로를 입력하고 저장하신 후 실행해보세요.
  • 만약 제대로 시작되거나 접속되지 않는 경우 전부 다 백업하신 후 지워서 깨끗한 상태에서 다시 설치해보시길 바랍니다.
