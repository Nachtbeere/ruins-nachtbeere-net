일반 밤딸기 플레이스 웹 페이지가 개장되었습니다

관리자 2015.11.27 11:59 조회 수 : 424

11월 10일부터 작업을 시작해 27일에서야 끝이 났습니다. 왜 이리 오래 걸렸는지는 모르겠지만 일단 완성이 되었네요.

 

이제 위키 문법에 익숙하지 않은 분들도 자유롭게 글을 작성하실 수 있고, 남들에게 알려줄 때도 접근하기 편하기에

 

여러분께 조금은 도움이 되길 바라겠습니다.

 

 

게임과 연동되는 주요 기능은 다음과 같습니다

  • 화이트리스트
    • 가입시 마인크래프트 닉네임 입력 시 모장 서버와 통신하여 UUID를 DB에 자동 등록.
    • 없거나 잘못된 닉네임/UUID라면 가입 제한.
    • 마인크래프트 닉네임 미기입시 가입에 제한 없음.
    • 가입 당시 마인크래프트가 없던 유저도 정보 수정에 입력시 반영 됨.
    • 기존 유저도 새 아이디를 구매했다면 정보 수정시 반영 됨.
    • 마인크래프트 닉네임을 변경해도 UUID 기반이므로 수정 불필요.
  • 순위
    • 재산 순위(아직 안돼요)
    • 직업 순위(아직 안돼요)
